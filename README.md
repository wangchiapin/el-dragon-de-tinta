# 墨龍飛天（El dragón de tinta）

> 水墨風的向上飛行遊戲：操控一條會飛的龍，只吃指定主題裡的字。

- **網址：** https://wangchiapin.github.io/el-dragon-de-tinta/
- **對象：** 學中文的西語學生（介面支援 中＋西／中＋英／只有中文）
- **狀態：** v1-8，排行榜尚未接上

## 玩法

- 龍在畫面下方往上飛，字從上面掉下來，左右（也可以上下）移動去吃。
- 開始前先選一個主題，只吃那個主題的字：吃對加分，連續吃對分數加倍；吃到別的主題的字，扣一顆愛心。三顆愛心用完就結束。
- 每吃對 8 個字加速一次，畫面上會顯示飛行高度。
- 第 2 級以後，錯誤的字會慢慢混進「相近主題」的字（例如食物裡混進水果、家具），越飛越難分。
- 龍頭會朝著移動的方向轉，往下退時可以整個轉到朝後，身體順著路徑跟在後面；慢下來就轉回朝上。龍可以飛到主題標籤的正下方。
- 畫面左右相連：龍從最左邊飛出去會從最右邊出現，反過來也一樣，身體一節一節跟著穿過去。
- 結束畫面有**複習清單**：列出這局吃錯、漏掉的字（字、拼音／注音、翻譯），點一下可以聽讀音。
- 右上角有 ♪（背景音樂開關）、暫停鍵、⚙️ 設定。切到別的程式時會自動暫停。
- 吃到字時（對的和錯的）都會念出該字的讀音（瀏覽器的語音，講台灣國語；手機沒有中文語音就不會出聲），念的時候背景音樂會小聲一點。
- **操作：** 手機用手指在畫面上拖動；電腦用方向鍵、WASD 或滑鼠拖動。

## 主題字庫

目前內建 10 個主題，每個 20 個詞（共 200 個），每個詞附拼音和中西英對照：

食物、水果、動物、顏色、交通、身體、衣服、職業、天氣、家裡。

字庫寫在 `index.html` 裡的 `THEMES`，格式是 `[繁體, 簡體, 拼音, 西文, 英文]`。要新增主題或詞，照這個格式加進去就可以（拼音要帶聲調符號，注音會自動轉換；同一個字不要出現在兩個主題）。`SIMILAR` 是每個主題對應的「相近主題」，高等級的干擾字會從那裡挑。

## 基本設定（⚙️）

和跑吧、色數消消樂、比比看共用同一把 localStorage 鑰匙 `hanziGames.settings`，學生在一款設好，這款也一樣：

| 欄位 | 值 | 說明 |
|---|---|---|
| `script` | `trad`／`simp` | 字形 |
| `lang` | `es`／`en`／`zh` | 中＋西／中＋英／只有中文 |
| `phon` | `pinyin`／`zhuyin`／`both`／`off` | 拼音、注音、兩個都顯示、關 |
| `rate` | `slow`／`normal`／`fast` | 語音速度（慢 0.45／正常 0.65／快 0.85，統一用 zh-TW 語音）|

遊戲自己另存的資料：`dragonInk.theme`（上次選的主題）、`dragonInk.name`（名字）、`dragonInk.music`（背景音樂開關）、`dragonInk.best.<主題>`（每個主題的本機最高分）。

## 畫面風格

水墨風：宣紙底、兩側淡墨山壁和雲霧隨著飛行往下捲動；字是墨點，龍是毛筆畫出來的線條。整幅畫只有一個朱紅色的太陽，龍的鬃毛和眼睛是另一點紅。

全部用 canvas 程式畫出來，沒有任何圖片檔。背景音樂和音效也是程式合成的，沒有音檔：

- **背景音樂：** D 五聲音階的固定旋律（4 個樂句排成 8 句一輪），古箏撥弦當旋律和低音、二胡拉長音、鼓和木魚打節拍、每輪開頭一聲鑼，加一點山谷的迴音。越飛越高，速度越快。
- **音效：** 吃對＝古箏往上刷；吃錯＝木魚加低沉的鑼；升級＝一串往上的古箏；結束＝古箏往下加鑼和二胡長音。
- 樂句和樂器都在 `index.html` 的 `PHR`、`ERHU`、`SONG` 和 `zheng`／`erhu`／`wood`／`drum`／`gong` 幾個函式裡，要改旋律或音色可以從那裡下手。

## 排行榜（待接）

`index.html` 裡有一段 `LEADERBOARD`（`enabled: false`），結束時會呼叫 `submit(entry)`，`entry` 的內容是：

```
{ name, theme, score, correct, altitude, ts }
```

接上時：把 `enabled` 改成 `true`，補上 `submit`（寫入 Firestore）和 `top`（讀前幾名）兩個函式，再在結果畫面的 `#lbBox` 顯示。
